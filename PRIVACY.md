# Prompt Library — プライバシーポリシー / Privacy Policy

最終更新 / Last updated: 2026-10-18

## 日本語

Prompt Libraryは、Microsoft Edge内で動作するローカル専用のプロンプト管理拡張機能です。

### 保存するデータ

登録したプロンプトのタイトル・本文・タグ・お気に入り、コピーした回数と最終使用日時、作成日時、表示と操作の設定、編集中の書きかけを、端末内の拡張機能ストレージに保存します。これらは機能提供のためだけに使用します。

### 外部通信・外部送信

この拡張機能は外部通信を一切行いません。保存した情報を開発者や第三者へ送信しません。分析ツール、広告、トラッキング、AI API、外部フォント、アカウント登録、自動同期はありません。

ユーザーの操作によって、プロンプト本文をOSのクリップボードへコピーします。クリップボードを読み取る機能はありません。クリップボードの管理・同期は、OSやユーザーが使用する他のソフトウェアの設定に従います。

### バックアップ・共有

明示的な操作によって、ブラウザーのダウンロード機能でJSONファイルを書き出します。バックアップには全プロンプト、設定、使用履歴が含まれます。共有用のプロンプト集には、選択したプロンプトのタイトル・本文・タグ・IDが含まれ、お気に入り状態・設定・使用履歴は含まれません。ファイルの送信や共有は、この拡張機能では行いません。

### 閲覧・変更・削除

保存したプロンプトはライブラリーと編集画面で閲覧・変更できます。設定画面からJSONバックアップを書き出せます。端末間の自動同期は行いません。

プロンプトは編集画面から削除できます。拡張機能をアンインストールすると、ブラウザーの仕様に従って端末内の拡張機能データが削除されます。書き出し済みJSONファイルやクリップボードの内容は別途管理してください。

## English

Prompt Library is a local-only prompt management extension for Microsoft Edge.

### Stored data

The extension stores prompt titles, content, tags, favorites, copy counts, last-used timestamps, creation timestamps, preferences, and unfinished editing drafts in the extension's local storage on your device. This information is used only to provide its features.

### External connections and transmission

The extension makes no external connections and sends no stored information to the developer or any third party. It includes no analytics, advertisements, tracking, AI APIs, external fonts, accounts, or automatic sync.

When you choose to copy a prompt, the extension writes its content to the operating system clipboard. It does not read the clipboard. Clipboard management and synchronization depend on your operating system and any other software you use.

### Backups and sharing

At your explicit request, the extension exports JSON files using the browser's download feature. Backups include all prompts, settings, and usage history. Shared collections contain the selected prompts' titles, content, tags, and IDs, excluding favorite status, settings, and usage history. The extension does not send or share these files.

### Access, changes, and deletion

You can view and edit saved prompts in the library and editor, and export a JSON backup from Settings. The extension does not automatically synchronize data between devices.

You can delete individual prompts from the editor. Uninstalling the extension removes its local extension data according to the browser's behavior. Exported JSON files and clipboard contents must be managed separately.
